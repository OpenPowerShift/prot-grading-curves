== Versioning

The language carries an implicit major version identified by the
source-file extension. *Initial major version: 0.1.0* -- declared on
the line `:version:` in `spec.adoc`. Breaking changes collect into a
new major with a new extension: `.tc2`, etc.

The processor reports both its own version and the parsed language
version on `--version`:

[source,console]
----
$ tc-curves --version
tc-curves 0.1.0  (language spec 0.1.0)
----

The language version is incremented in lockstep with `tc-curves` only
when *grammar* changes; pure renderer / UX changes ride the language
version unchanged.

* *Patch* `0.0.x` -- no grammar, no new identifiers. Beautification.
* *Minor* `0.1.x` -- additive grammar (new keywords, new curve names,
  new lints). Existing files still parse.
* *Major* `0.2.0` (future) -- first potentially-breaking change.

=== Roadmap

[cols="1,3", options="header"]
|===
| Version | Planned features

| 0.1.x    | Core language: IEC/IEEE curves, multi-stage elements, `combine`, `solve` (text), cross-voltage grading, devices, `page`/theme, SVG/PNG/PDF export.
| 0.2.0    | Interactive curve dragging in the playground (reverse-solve `tms`/`I_pickup`/`t_delay` from visual position, write back to source); `solve { free = ["tms", "I_pickup"]; }` two-variable Newton; `safety_factor` solver strategy; directional element logic; per-element `style` override.
|===
